실시간 1vs1 멀티플레이어 트레이딩 카드 게임 · Unity + Photon PUN2

3,000+
코드 라인
5+
카드 타입

턴 타이머

OVERVIEW

Photon PUN2의 MasterClient 권한 모델을 활용해 실시간으로 두 플레이어가 대전하는 TCG 게임입니다. 캐릭터·스킬·필살기·리더·영속 카드 5가지 타입을 구현하고, 상대 리더의 HP를 0으로 만들면 승리합니다.

핵심 구현

  • Master/Client 이중 검증 — 요청 RPC → 검증 → 실행 RPC 2단계로 치트 방지
  • 카드명 기반 동기화 — ScriptableObject 전송 제약을 string 배열 + 로컬 DB 조회로 해결
  • 영속 카드 강제 동기화 — 매 턴 종료 시 ViewID 배열 브로드캐스트로 상태 불일치 방지
  • AuthorityRng — 마스터만 난수 결정, 양 클라이언트 확률 결과 일치 보장
  • 쿨타임·확률 기반 어빌리티 시스템 — TriggerType × 발동 확률 × 쿨타임 조합
  • 상태 이상 시스템 — 부식 · 수면 · 최후의 성역 · 천상의 축복 · 드로우 차단
  • OnPlayerLeftRoom 콜백으로 상대 이탈 시 자동 승패 처리

해결한 기술 문제

  • 덱 상태 불일치 — 마스터가 드로우 결과를 결정 후 RPC 전파, 클라이언트 독립 셔플 제거
  • 영속 카드 지속 턴 어긋남 — 턴 종료마다 슬롯 전체 강제 동기화로 해결
  • 이중 처리 버그 — IsMasterClient 가드 + 재진입 방지 플래그(_isEndingTurn) 적용

UX Research 소논문 2024

OVERVIEW

게임 UI/UX 관점에서 사용자 경험을 분석하고 개선 방향을 제시한 소논문입니다. 이벤트연출 전공 배경과 소프트웨어 개발 역량을 결합하여 사용자 중심의 게임 설계 방법론을 연구했습니다.

연구 포인트

  • 게임 UI에서의 사용자 흐름(User Flow) 분석
  • 이벤트연출 전공 지식을 게임 UX에 접목
  • 피드백 루프와 인지 부하 최소화 전략 연구
