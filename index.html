프로젝트 개요

최대 4명의 플레이어가 실시간으로 협력하여 적을 물리치는 탑다운 슈팅 게임입니다. Photon PUN2를 활용하여 안정적인 멀티플레이어 환경을 구축했으며, 각 플레이어의 역할과 무기 시스템을 차별화하여 전략적 플레이를 유도했습니다.

기술 스택

Unity 2022.3 Photon PUN2 C# ScriptableObject Object Pooling RPC

핵심 기능

  • 실시간 4인 멀티플레이어 매칭 및 동기화
  • 플레이어별 차별화된 무기 시스템 (총기, 근접, 마법)
  • 서버 권한 기반 적 AI 및 아이템 스폰 관리
  • 낮은 레이턴시 환경에서 부드러운 이동 및 전투 구현
  • Object Pooling을 활용한 최적화

TECHNICAL CHALLENGE

문제 해결 과정

개발 중 마주한 기술적 도전과 해결 방법입니다.

CHALLENGE 01

네트워크 동기화 지연 문제

문제: 플레이어 간 이동과 공격 동기화에서 최대 200ms의 지연 발생. 특히 빠른 이동 중 위치 불일치로 인한 플레이 경험 저하.

해결: Photon의 Lag Compensation과 클라이언트 예측(Client Prediction)을 도입. 로컬에서 즉시 이동 처리 후 서버 검증 방식으로 전환하여 체감 지연을 50ms 이하로 감소.

// 클라이언트 예측 이동 로직
void Update() {
  if (photonView.IsMine) {
    transform.position += input * speed * Time.deltaTime;
    photonView.RPC("SyncPosition", RpcTarget.Others, transform.position);
  }
}
CHALLENGE 02

대량 발사체 처리로 인한 성능 저하

문제: 4명의 플레이어가 동시에 총알을 발사할 때 프레임 드롭 발생 (60fps → 30fps). 매 프레임마다 수백 개의 발사체 Instantiate 및 Destroy 호출.

해결: Object Pooling 패턴 도입. 발사체를 미리 생성하고 재사용하는 구조로 변경하여 프레임 안정화 (평균 58fps 유지).

// Object Pool 발사체 재사용
Projectile proj = ProjectilePool.Instance.Get();
proj.Initialize(direction, damage);
// 충돌 후
ProjectilePool.Instance.Return(proj);
CHALLENGE 03

적 AI 스폰 동기화 불일치

문제: 각 클라이언트에서 독립적으로 적을 스폰하여 서로 다른 적 수와 위치가 나타남. 협동 플레이 전략 불가능.

해결: Master Client가 적 스폰을 전담하고 RPC를 통해 모든 클라이언트에 동일한 적 정보 전송. 씬 전환 시에도 일관성 유지 로직 추가.

// Master Client에서만 적 스폰
if (PhotonNetwork.IsMasterClient) {
  Vector3 spawnPos = GetRandomSpawnPoint();
  photonView.RPC("SpawnEnemy", RpcTarget.All, spawnPos, enemyID);
}
