CHALLENGE 01

오디오 믹서 볼륨 초기화 문제

문제: 씬 전환 후 BGM 볼륨이 -80dB로 초기화되어 소리가 들리지 않음. AudioMixer.SetFloat()가 즉시 적용되지 않고 프레임 지연 발생.

해결: Coroutine을 활용하여 1프레임 대기 후 볼륨 복구 로직 구현. 씬 전환 시 안정적인 오디오 재생 보장.

private IEnumerator Coroutine_ResetAudioMixer() {
  audioMixer.SetFloat("BGMVolume", -80f);
  yield return null; // 1프레임 대기
  SetBGMVolume(targetBgmVolume); // 복구
}
CHALLENGE 02

Spatial Audio Source Pooling

문제: 동시에 많은 3D 사운드 재생 시 성능 저하 및 AudioSource 중복 생성 발생.

해결: 32개의 AudioSource Pool을 사전 생성하고, 거리 기반 우선순위 시스템으로 가장 가까운 사운드만 재생. 메모리 효율 향상 및 자연스러운 음원 페이드.

// 거리 기반 우선순위 정렬
virtualSounds = virtualSounds
  .OrderBy(vs => Vector3.Distance(
    vs.position, listener.position))
  .ToList();
CHALLENGE 03

Firebase Quaternion 회전 감지 정확도

문제: Quaternion 값이 미세하게 변해도 회전으로 인식되어 오차 누적.

해결: 각도 차이 누적 방식 사용. 360도 기준으로 정확한 회전 카운트 및 잔여 각도 보존으로 연속 회전 지원.

float deltaAngle = Quaternion.Angle(
  lastRotation, currentRotation);
accumulatedAngle += deltaAngle;

if (accumulatedAngle >= 360f) {
  RotationCount++;
  accumulatedAngle -= 360f; // 오차 보정
}
